# Use Cloudflare native tooling for DNS and infrastructure management

## Rationale

DNS is on Cloudflare. Using Cloudflare-native tools (Workers, Analytics, Cache Rules, Observatory, Speed tests, Health Checks) avoids third-party overhead, gives direct access to real CDN/edge metrics, and keeps tooling in one control plane. Alternatives like external monitoring platforms or third-party DNS tools add cost and latency without benefit when Cloudflare already owns the edge.

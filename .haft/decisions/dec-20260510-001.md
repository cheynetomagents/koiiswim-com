# Audit koiiswim.com with Rip Curl as peer control + Shopify published benchmarks as platform floor

## 1. Problem Frame

**Signal:** No current performance/reliability metrics exist. Cannot measure impact of future SRE changes without a baseline.

**Constraints:**
- Read-only — no changes to the live Shopify site during baselining
- Must capture metrics before any SRE work begins

**Acceptance:** Baseline report exists with: Core Web Vitals (LCP, CLS, INP), TTFB, availability, page weight, and Lighthouse scores for key pages (home, PDP, cart). All metrics timestamped and stored in repo.

## 2. Decision

**Selected:** Audit koiiswim.com with Rip Curl as peer control + Shopify published benchmarks as platform floor

**Selection policy:** Choose control group that is (1) publicly auditable without accounts, (2) on Shopify, (3) in adjacent vertical, (4) uses documented platform benchmarks for floor. Rip Curl + Shopify docs satisfies all four. Rejected alternatives failed on at least one.

**Why selected:** Rip Curl is a confirmed Shopify swimwear/surf brand — same platform, adjacent vertical, publicly auditable. Shopify's published Lighthouse floor (≥60, weighted across home/product/collection) and JS budget (≤16KB) give a documented platform minimum without needing to spin up a test store. Together they provide two reference points: industry peer and platform floor.


**Invariants:**
- Audit is read-only — no writes to any live store
- All metrics timestamped at capture time
- Same audit tool and settings used for koiiswim.com and Rip Curl

**Pre-conditions:**
- [ ] No changes made to koiiswim.com before audit runs
- [ ] Audit tools confirmed working (Lighthouse/PageSpeed reachable)

**Post-conditions:**
- [ ] Lighthouse scores captured for home, product, collection pages on both koiiswim.com and ripcurl.com/us
- [ ] Core Web Vitals (LCP, CLS, INP) recorded for both
- [ ] TTFB recorded for both
- [ ] SEO audit (meta, structured data, sitemap, canonicals, robots.txt) complete for koiiswim.com
- [ ] AI optimization audit (llms.txt, schema markup) complete for koiiswim.com
- [ ] All results stored in repo under /baseline/
- [ ] Shopify floor benchmarks documented alongside results

**Admissibility:**
- NOT: Do not use lab-only metrics without noting they are synthetic
- NOT: Do not compare koiiswim.com to Rip Curl on metrics affected by catalog size or app count without noting the caveat

## 3. Rationale

**Counterargument:** Rip Curl is a large global brand with Shopify Plus and a dedicated engineering team — their scores likely reflect investment we can't replicate, not just platform capability, making the comparison potentially demoralizing or misleading as a peer target.

**Selected variant weakest link:** Rip Curl's theme complexity and app count are unknown — if heavily customized, their scores skew high and don't represent a fair peer baseline for a small swimwear brand.

**Rejected alternatives:**
| Variant | Verdict | Reason |
|---------|---------|--------|
| Audit koiiswim.com with Rip Curl as peer control + Shopify published benchmarks as platform floor | **Selected** | Rip Curl is a confirmed Shopify swimwear/surf brand — s... |
| Free Shopify trial store with Dawn | Rejected | Requires creating an account, adds friction, and a zero-product store doesn't reflect real-world Shopify performance under actual catalog/app load. |
| Shopify published CWV aggregates only | Rejected | No CWV-specific numbers published — only Lighthouse floor of 60, insufficient for full baseline comparison across all target metrics. |

**Evidence requirements:**
- Lighthouse JSON output for 3 page types per site
- PageSpeed Insights CWV field data if available for koiiswim.com
- HTTP header dump for caching/compression/security headers
- SEO crawl output: meta tags, structured data, sitemap, robots.txt
- llms.txt check and schema markup inventory

**Predictions:**
| Claim | Observable | Threshold |
|-------|------------|-----------|
| koiiswim.com Lighthouse score is below Shopify floor of 60 on at least one page type | Lighthouse performance score | < 60 on home, product, or collection |
| koiiswim.com has no llms.txt file | HTTP response for /llms.txt | 404 or missing |
| koiiswim.com is missing structured data on product pages | Schema.org JSON-LD presence on PDPs | absent or incomplete Product schema |

## 4. Consequences

**Rollback plan:**
Triggers:
- Audit tooling produces inconsistent results across two runs (>10 point Lighthouse variance)
Steps:
1. Discard results
2. Re-run audit in consistent network/device conditions
3. Document variance cause before re-baselining

**Refresh triggers:**
- After any SRE change is deployed to koiiswim.com
- If Rip Curl relaunches with a new theme
- If Shopify updates published performance benchmarks

**Affected files:** baseline/koiiswim-home.json, baseline/koiiswim-product.json, baseline/koiiswim-collection.json, baseline/ripcurl-home.json, baseline/ripcurl-product.json, baseline/ripcurl-collection.json, baseline/seo-audit.md, baseline/ai-optimization-audit.md

# Monitoring and alerting for koiiswim.com availability

## Signal

No monitoring exists. Site outages, Shopify maintenance mode, DNS failures, and SSL expiry go undetected until a customer reports them.

## Problem Type

search

## Constraints

- Cloudflare plan is Free — no native Health Checks available
- Must alert to phone via SMS or existing Netdata app (no new app installs)
- Must not require paid SaaS monitoring platforms

## Optimization Targets

- Time-to-alert on outage (minimize)
- Setup complexity (minimize)

## Observation Indicators

- False positive rate
- Monitoring instance uptime

## Acceptance

Alerts fire to phone within 2 minutes of koiiswim.com being unreachable. Covers HTTP uptime, DNS resolution, SSL expiry, and Shopify maintenance mode detection.

## Blast Radius

Monitoring infrastructure only — no changes to koiiswim.com or Cloudflare config

## Reversibility

high

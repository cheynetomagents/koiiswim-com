# Establish a Shopify staging environment for safe testing and deployment

## Signal

Currently, theme changes and app integrations are tested directly on the live koiiswim.com production store (or via preview themes), which is high-risk and lacks isolated data for destructive testing.

## Problem Type

synthesis

## Constraints

- Must be password protected to prevent SEO indexing/public access
- Must minimize or eliminate additional Shopify subscription costs (prefer Development Store)
- Theme must stay in sync with production for accurate testing

## Optimization Targets

- Production parity (theme and settings)
- Ease of synchronization from production to staging

## Acceptance

A functional Shopify staging environment exists (e.g., koiiswim-staging.myshopify.com) with production theme parity, password protection, and representative test data. Changes can be validated here before production deployment.

## Blast Radius

Staging environment and development workflow only. No impact on production customer traffic or revenue.

## Reversibility

high

# Establish koiiswim.com baseline metrics before SRE changes

## Signal

No current performance/reliability metrics exist. Cannot measure impact of future SRE changes without a baseline.

## Problem Type

diagnosis

## Constraints

- Read-only — no changes to the live Shopify site during baselining
- Must capture metrics before any SRE work begins

## Optimization Targets

- Capture comprehensive baseline across performance, availability, and UX metrics

## Observation Indicators

- Shopify platform limits (not in our control)
- External CDN/DNS latency
- Third-party app load impact

## Acceptance

Baseline report exists with: Core Web Vitals (LCP, CLS, INP), TTFB, availability, page weight, and Lighthouse scores for key pages (home, PDP, cart). All metrics timestamped and stored in repo.

## Blast Radius

Read-only audit — no production impact

## Reversibility

high
